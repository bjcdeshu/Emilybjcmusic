## Playback contract

The frontend must use an actual HTML audio element: real currentTime/duration, ended/error/pause/play events, honour user pause, and surface autoplay rejection. No ticking simulated progress. Play optional prepared DJ audio, then the current song, then advance the queue. Preload/prefetch where useful without playing before user activation. Media Session controls refer to actual audio state. Volume ducking/transition should be modest; avoid a large sound burst at DJ/song boundaries. Background playback on the physical Xiaomi is not proved by desktop emulation.
